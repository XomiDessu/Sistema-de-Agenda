Nota sobre Gmail: la aplicación no implementa conexión OAuth ni Gmail API de forma directa. El envío real se realiza mediante EmailJS desde el navegador; Gmail puede configurarse como servicio dentro de EmailJS. La conexión y entrega reales quedan sin confirmar hasta aportar una configuración válida y probar el correo.

1admin/users.js, session.js, storage.jsRiesgo alto: las cuentas, roles, estado y permisos residen en almacenamiento del navegador. La verificación de administrador es lógica cliente; no proporciona control fiable ante usuarios que puedan modificar el almacenamiento. Para producción, aplicar autorización en servidor.EEquipo de desarrolloAbierto
